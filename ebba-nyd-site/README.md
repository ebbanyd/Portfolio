# Ebba Nyd: website

**To edit the site, only change `content.js`.** Put images in the `images` folder.

1. Open this folder in VS Code.
2. Right-click `index.html` → "Open with Live Server" to preview.
3. Edit `content.js`, save, and check the preview.
4. Source Control → write a message → Commit → Sync. The site updates in about a minute.
